# Eric’s World｜艾瑞克的日常

張維峻 Eric Chang 的個人網站。

網站：https://ericchang715.github.io/marketing/explore-with-eric/

## 內容

首頁、故事、工作、生活與自由探索。以使用者上傳的原始照片介紹校園教材工作與生活記錄，支援手機瀏覽。

## 修改方式

- `index.html`：個人介紹、各頁文字與作品連結。
- `style.css`：色彩、版面與手機樣式。
- `app.js`：頁面導覽與故事章節切換。
- `assets/eric-portrait.jpg`：使用者原始照片，未修改人物外貌。

此目錄為獨立靜態網頁，沿用儲存庫既有 GitHub Pages 設定，無需安裝套件或建置。

版面風格參考 https://kevin960314.github.io/explore-with-kevin/ 。程式與文案重新製作，未複製參考網站的人物照片或插畫。
